# tv

Телепрограмма двадцати эфирных каналов — двух мультиплексов РТРС — без рекламы,
трекеров и сторонних доменов.

Личный проект: сервис поднят дома для себя. Код открыт, данные — нет (см. ниже).

## Чем отличается от готовых сайтов

Страница телепрограммы `tv.mail.ru` на одни сутки — 2.93 МБ в 60 запросах:
717 КБ HTML, 508 КБ Google Tag Manager, обращения к трём рекламным и
телеметрическим доменам, детект блокировщика. Здесь тот же день весит 15 КБ и
грузится одним запросом.

Разница не в оптимизации, а в том, когда делается работа: страницы рендерятся,
сворачиваются и сжимаются в момент **загрузки данных**, дважды в сутки, и лежат
в памяти готовыми. На запрос приходится взятие из map и запись готовых байтов —
без SQL, без шаблонизатора, без гидратации.

Отсюда же следствие, ради которого всё и затевалось: **недоступность источника
не влияет на доступность сайта**. Холодный старт при мёртвом фиде отдаёт
последнюю сохранённую сетку.

## Стек

Bun + TypeScript, SQLite, ноль рантайм-зависимостей. Разметка серверная,
фреймворка нет: весь клиент — 4 КБ, и он ничего не рендерит, только отвечает на
два вопроса, которых сервер знать не может, — который час и какие каналы выбрал
этот посетитель. Отдельного шага сборки фронтенда тоже нет: клиент собирается
`Bun.build` на старте процесса, поэтому в образе только исходники.

## Данные

Официального API телепрограммы у российских вещателей нет — их собственные
сайты ходят во внутренние ручки, закрытые анти-ботом. Поэтому источник —
публикуемый файл в стандартном формате XMLTV, а не чужой внутренний XHR.

**В репозитории нет ни одной строки расписания**: сервис скачивает его сам, и
файл базы в git не попадает. Права на сами данные принадлежат вещателям, лицензия
ниже распространяется только на код.
